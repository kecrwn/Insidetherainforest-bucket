## 📖 About

This repository serves as the official static media asset bucket and digital content repository for **[Inside The Rainforest](https://github.com/kecrwn/InsideTheRainForest)**. 

It stores high-resolution photography, 4K looping background hero video clips, and visual documentation capturing the rainforest ecosystems of Borneo and Sumatra, highlighting endangered orangutans (*Pongo pygmaeus* / *Pongo abelii*), forest canopies, community conservationists, and the environmental impact of deforestation.

---

## 📸 Asset Catalog

### 🦧 Orangutan Portraits & Behavior
- `orangutan_closeup[1-5].jpg` — High-detail macro portraits documenting facial expressions, eyes, and fur textures.
- `orangutan_canopy[1-3].jpg` — Orangutans traversing canopy layers and constructing arboreal night nests.
- `orangutan_eating[1-4].jpg` — Foraging behaviors, wild fig consumption, and jungle dietary patterns.

### 🌿 Rainforest Vistas & Landscapes
- `rainforest_landscape[1-3].jpg` — Panoramic vistas of ancient dipterocarp canopies, river mist, and lush peatland forests.

### ⚠️ Deforestation & Threat Documentation
- `deforestation_threat[1-3].jpg` — Clear-cut concessions, heavy machinery encroachments, and fire-damaged borderlands.

### 🤝 Community & Conservation Teams
- `community_[1-12].jpg` — Local wildlife rangers, indigenous patrol groups, veterinary rescue operations, and tree planting teams.

### 🎬 High-Definition Hero Video Reels
- `hero_background.mp4` & `hero_background2.mp4` — Looping, cinematic web-optimized video reels tailored for hero landing page backdrops.

## 🚀 Usage & Integration

### As a Git Submodule
Integrate directly into web applications:
```bash
git submodule add https://github.com/kecrwn/Insidetherainforest-bucket.git public/media
```

### Direct Raw GitHub CDN
Access media assets directly via GitHub's raw content delivery network:
```html
<img 
  src="https://raw.githubusercontent.com/kecrwn/Insidetherainforest-bucket/main/orangutan_closeup.jpg" 
  alt="Wild Orangutan in Borneo" 
  loading="lazy" 
/>
```
